# Sunstone Gambit

An original, 100% offline tactical suit-combo card duel built for [make.fun](https://make.fun/r/41fw6r6c) (`best-card-game-20261122-1826`).

## Highlights
- **Four Distinct Elemental Suits** (Solar, Tide, Verdant, Eclipse) differentiated by both bold color palettes and geometric emblems.
- **Multi-Axis Combos**: Chain **Suit Resonance**, **Value Pairs & Ascending Cascades**, and **Elemental Counter-Clashes** against an opponent whose telegraphed cards you can read and outplay.
- **Tactile Feel & Polish**: Spring-physics dealing and fanning, 3D card flips, hover tilt with foil sheen, combo arcs, hitstop, particle bursts, and procedural Web Audio sound effects.
- **Full Keyboard & Mouse Controls**: Hover/click/drag cards, `1`–`5` or `←`/`→` + `Enter`/`Space` to play, `S` to swap, `E` to end turn, `H` for rules overlay, `M` to mute, `R` for rematch.

## Run Locally
```bash
node serve.ts
# Open http://localhost:8080 in Chrome
```

## Build Dossier Output
```bash
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
